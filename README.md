# Мелодия Гитар

Небольшой интернет-магазин музыкальных инструментов на FastAPI + SQLAlchemy + SQLite с публичным каталогом и простой админ-панелью.

## Запуск на Windows

1. Откройте папку проекта в терминале.
2. Создайте виртуальное окружение:

```bash
python -m venv venv
venv\Scripts\activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Проверьте `.env`. Для работы в локальной сети задайте свой пароль и `SECRET_KEY`.

5. Запустите:

```bash
uvicorn app.main:app --reload
```

Магазин: http://127.0.0.1:8000/

Документация API: http://127.0.0.1:8000/docs

Админка: http://127.0.0.1:8000/admin/login

## Что умеет админка

- категории: создание, редактирование, удаление, иконка и фото;
- товары: создание, редактирование, удаление, фото, цена, описание, характеристики и наличие;
- заказы: просмотр состава и изменение статуса;
- загружаемые изображения проверяются через Pillow и сохраняются в `app/static/uploads/` под случайными именами;
- формы админки защищены сессионной авторизацией и CSRF-токеном.

## Переменные `.env`

`ADMIN_PASSWORD` — пароль администратора.

`SECRET_KEY` — секрет для подписи сессионной cookie.

`DATABASE_URL` — URL базы данных. По умолчанию используется `data/melody.db`.

`SEED_DEMO_DATA=true` — автоматически заполнить пустую БД 6 категориями и 8 демонстрационными товарами.

`MAX_UPLOAD_MB=5` — максимальный размер изображения.

## Важно

Демонстрационные изображения используют внешние URL Unsplash. Фото, загруженные через админку, обслуживаются самим FastAPI из `/static/uploads/...`.


## Быстрый запуск на Windows

Запусти файл `start.bat` двойным кликом. Он создаст `venv`, установит зависимости, запустит FastAPI и откроет магазин в браузере.

Магазин: `http://127.0.0.1:8000/`
Админка: `http://127.0.0.1:8000/admin/login`
API: `http://127.0.0.1:8000/docs`

Чтобы остановить сервер, закрой окно `Melody Guitars Server`.

### Запуск через start.bat

На Windows достаточно дважды нажать `start.bat` в папке проекта.
Скрипт создаст виртуальное окружение, установит зависимости, запустит сервер и откроет магазин в браузере.

Если Windows показывает ошибку «Синтаксическая ошибка в имени файла, имени папки или метке тома», используй обновлённый `start.bat` из этой версии проекта.
